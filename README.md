# Document Studio — downloads

Open, edit, combine and create PDFs and images on Windows. Works offline, no account needed.

**[Download the latest version](https://github.com/sethmart15-34/document-studio-releases/releases/latest/download/DocumentStudioSetup.exe)** (Windows 10/11, about 120 MB)

- Windows may say "Windows protected your PC" the first time: click **More info**, then **Run anyway**.
- Once installed, Document Studio updates itself: when a new version is ready it shows **Restart now**.

This repository only holds the installers and update files. The source code is not published here.
